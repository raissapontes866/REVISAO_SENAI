⭕ 1. Circunferência

A circunferência é uma linha fechada formada por todos os pontos que estão à mesma distância de um ponto central chamado de centro.

Fórmula do comprimento

C = 2πr
  • C = comprimento da circunferência
  • π ≈ 3,14
  • r = raio

Exemplo

Se o raio de uma circunferência é 5 cm:

C = 2 · π · 5

C ≈ 2 · 3,14 · 5

C ≈ 31,4 cm

📍 2. Distância entre dois pontos

Para descobrir a distância entre dois pontos no plano cartesiano, usamos o Teorema de Pitágoras.

Fórmula

d = √[(x₂ - x₁)² + (y₂ - y₁)²]

Exemplo

Considere os pontos:

A(2, 3) e B(6, 6)

d = √[(6 - 2)² + (6 - 3)²]

d = √[4² + 3²]

d = √[16 + 9]

d = 5

🔺 3. Baricentro

O baricentro é o ponto de encontro das três medianas de um triângulo.

Fórmula

G = ((x₁ + x₂ + x₃) / 3, (y₁ + y₂ + y₃) / 3)

Exemplo

Considere os pontos:

A(1, 2), B(4, 5) e C(7, 2)

xG = (1 + 4 + 7) / 3 = 4

yG = (2 + 5 + 2) / 3 = 3

G = (4, 3)

📝 4. Exercícios para praticar

Questão 1

Uma circunferência possui raio igual a 10 cm. Considerando π = 3,14, qual é aproximadamente o seu comprimento?

Resposta: 62,8 cm.

Questão 2

Qual é a distância entre os pontos A(1, 2) e B(4, 6)?

Resposta: 5 unidades.

Questão 3

Determine o baricentro do triângulo formado pelos pontos A(0, 0), B(6, 0) e C(3, 6).

Resposta: G(3, 2).
